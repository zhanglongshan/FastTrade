# 03 回测操作

## 页面回测

1. 先完成数据下载或导入，确认 **量化 → 下载** 的数据集列表中有记录。
2. 进入 **量化 → 回测**。
3. 在「新建回测」中选择：
   - 数据集：显示交易对、周期、K 线数量与数据集名称。
   - 策略：来自 `user_data/strategies/` 的自动发现结果。
   - 初始资金：默认 10000。
   - 手续费率：默认 0.001（单边 0.1%）。
   - 滑点：默认 0。
4. 点击 **开始回测**。回测同步执行，完成后页面显示结果。
5. 「历史回测」表可刷新并查看任意一次回测的详情。

## 结果字段

| 字段 | 含义 |
| --- | --- |
| `final_equity` | 期末账户净值 |
| `total_return` | 总收益率 = 期末净值 / 初始资金 - 1 |
| `annualized_return` | 按数据跨度折算的年化收益 |
| `max_drawdown` | 净值曲线最大回撤 |
| `trade_count` | 订单成交笔数（含开仓与平仓） |
| `closed_trade_count` | 已平仓笔数 |
| `win_rate` | 已平仓交易中盈利笔数占比 |
| `trades` | 成交流水：时间、方向、数量、价格、手续费、盈亏、原因 |
| `equity_curve` | 每根 K 线的净值点 |
| `logs` | 策略通过 `api.log()` 输出的日志 |

## CLI 回测

```bash
cd backend
# 先查询数据集ID（页面数据集表的 ID 列）
uv run python main.py quant strategies

uv run python main.py quant backtest --dataset 1 --strategy SmaCrossStrategy \
  --cash 10000 --fee 0.001 --slippage 0.0005
```

输出为 JSON 摘要，包含 `id`、`status`、`result` 等字段；完整流水同时入库，可在页面查看。

## 回测撮合细节

1. 回测按 K 线时间顺序逐根推进。
2. 第 `i` 根 K 线开盘时，先执行第 `i-1` 根产生的订单。
3. 随后调用策略逻辑生成新订单。
4. 最后一根 K 线的未成交订单按该根收盘价成交。
5. 指标接口 `api.sma/ema/rsi` 只使用 `0..i` 的收盘价，避免未来函数。

## 失败排查

- **未找到策略**：检查类名是否与页面展示一致，文件是否在 `user_data/strategies/`。
- **数据集为空**：确认 CSV 有数据行，且列名正确。
- **策略执行失败**：查看回测记录 `error` 字段与策略代码异常。
- **成交数为 0**：检查预热 K 线数、信号条件、`ratio` 参数，或数据长度是否过短。
- **收益率异常**：确认手续费与滑点设置，以及是否使用了不适合的周期/数据。
