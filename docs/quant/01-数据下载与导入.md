# 01 数据下载与导入

## 方式一：页面下载（推荐）

1. 启动后端与前端，登录管理台。
2. 进入 **量化 → 下载**。
3. 在「下载币安数据」卡片填写：
   - 交易对：如 `BTC/USDT` 或 `BTCUSDT`（系统会自动规范化）。
   - 周期：支持 `1m/3m/5m/15m/30m/1h/2h/4h/6h/8h/12h/1d/3d/1w/1M`。
   - 起止日期：留空时下载最近 30 天至当前时间。
   - 备注：可选。
4. 点击 **下载**。完成后页面显示写入路径、本次新增条数与合并后总条数。
5. 下方「已登记数据集」表会新增/更新一条记录。

文件保存位置：

```text
user_data/data/binance/BTCUSDT_1h.csv
```

重复下载同一交易对和周期时，系统会按 `date` 去重合并，不会覆盖历史数据。

## 方式二：命令行下载

```bash
cd backend
uv run python main.py quant download --symbol BTC/USDT --interval 1h --start 2024-01-01 --end 2024-06-30
# 或使用兼容别名
uv run python main.py mingling download -s ETH/USDT -i 4h --start 2024-01-01
```

输出为 JSON，包含 `file_path`、`downloaded`、`row_count`、`dataset_id`。

## 方式三：导入本地 CSV

CSV 必须包含表头：

```csv
date,open,high,low,close,volume
2024-01-01T00:00:00+00:00,42000,42500,41800,42300,1200
```

`date` 支持 ISO8601（推荐带时区）；数值列必须是数字。

### 页面导入

1. 进入 **量化 → 下载**。
2. 在「导入本地 CSV」中选择文件，填写交易对与周期。
3. 点击 **导入**。

可导入目录由后端限制为：

- `user_data/data/`
- `backend/data/quant/`

路径穿越（`../`）会被拒绝。

### 命令行导入

```bash
cd backend
uv run python main.py quant import user_data/data/my_data.csv --symbol BTC/USDT --interval 1h --source local
```

导入后文件会被归一化复制到：

```text
user_data/data/local_BTCUSDT_1h.csv
```

## 数据集字段说明

| 字段 | 说明 |
| --- | --- |
| `name` | `来源_交易对_周期`，如 `binance_btcusdt_1h` |
| `symbol` | 规范化后的交易对，如 `BTCUSDT` |
| `interval` | K 线周期 |
| `source` | `binance` 或自定义来源 |
| `file_path` | 相对项目根目录的 CSV 路径 |
| `row_count` | 去重合并后的 K 线数量 |
| `start_time` / `end_time` | 数据起止时间 |

## 常见问题

- **币安返回 451/限制访问**：检查网络出口与币安 API 可用性；命令会重试 3 次。
- **CSV 缺少必需列**：按上方表头补齐，列名区分大小写。
- **导入提示文件不在允许目录**：把文件复制到 `user_data/data/` 后重试。
- **下载很慢**：一次下载跨度较大时系统会分页请求并轻度限速，属正常现象。
