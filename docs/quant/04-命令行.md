# 04 命令行

所有命令在 `backend/` 目录执行。`quant` 为主命令名，`mingling` 为兼容别名，两者参数完全一致。

```bash
cd backend
uv run python main.py quant --help
uv run python main.py mingling --help
```

## 1. 列出策略

```bash
uv run python main.py quant strategies
```

输出示例：

```text
SMA均线交叉	event	1h	user_data/strategies/sma_cross_strategy.py
RSI超卖反弹	signal	1h	user_data/strategies/rsi_signal_strategy.py
```

## 2. 下载数据

```bash
uv run python main.py quant download \
  --symbol BTC/USDT \
  --interval 1h \
  --start 2024-01-01 \
  --end 2024-06-30 \
  --limit 1000 \
  --env dev
```

参数：

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `--symbol` / `-s` | 是 | 交易对，如 `BTC/USDT` |
| `--interval` / `-i` | 是 | K 线周期 |
| `--start` | 否 | 起始日期，默认近 30 天 |
| `--end` | 否 | 结束日期，默认今天 |
| `--limit` | 否 | 单页条数，默认 1000，上限 1000 |
| `--env` | 否 | 运行环境，默认 `dev` |

## 3. 导入 CSV

```bash
uv run python main.py quant import user_data/data/my_data.csv \
  --symbol BTC/USDT \
  --interval 1h \
  --source local \
  --env dev
```

`file_path` 是位置参数，必须在允许目录内（`user_data/data/` 或 `backend/data/quant/`）。

## 4. 执行回测

```bash
uv run python main.py quant backtest \
  --dataset 1 \
  --strategy SmaCrossStrategy \
  --cash 10000 \
  --fee 0.001 \
  --slippage 0.0005 \
  --env dev
```

参数：

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `--dataset` / `-d` | 是 | 数据集 ID，见页面数据集表 |
| `--strategy` / `-s` | 是 | 策略类名，见 `strategies` 命令输出 |
| `--cash` | 否 | 初始资金 |
| `--fee` | 否 | 单边手续费率 |
| `--slippage` | 否 | 滑点比例 |
| `--env` | 否 | 运行环境 |

## 5. 补入侧栏菜单（既有数据库）

量化页面在侧栏的「量化」目录由后端 `sys_menu` 表驱动：

- **全新安装**：`backend/sql/sys_menu.json` 已包含量化菜单，初始化时自动入库，无需操作。
- **既有数据库**：种子数据遵循「表已有数据则跳过」，升级后需执行一次以下命令补入菜单（幂等，可重复执行）：

```bash
cd backend
uv run python main.py quant init-menu --env=dev
```

执行后**重新登录前端**（或清掉用户信息缓存），侧栏即出现「量化 → 量化-下载 / 量化-回测」。

> 菜单 `scope=web`，超级用户自动可见；普通用户需在「系统管理 → 角色管理」中勾选量化菜单授权。

## 6. 与页面操作的关系

CLI 与页面调用同一套 service/engine：

- 下载/导入会写入同一批 CSV 与数据库数据集记录。
- 回测会写入同一张 `quant_backtest` 表，页面「历史回测」可查看 CLI 产生的记录。
- 因此 CLI 适合批处理与定时任务，页面适合交互式查看。

## 7. 环境变量

CLI 通过 `--env dev|prod` 决定加载 `backend/env/.env.dev` 或 `.env.prod`。数据库连接信息只从对应 env 文件读取，不通过命令行传递，避免密码进入 shell 历史。
