# 01 登录与个性化

## 登录页

访问管理台任意地址，未登录时自动跳转 `/login`。登录页由三部分构成：顶部导航栏（品牌、帮助、备案信息）与左右插画/表单列；屏宽不足时自动切换为居中布局。

### 登录方式

| 方式 | 入口 | 说明 |
| --- | --- | --- |
| 账号密码 | 登录表单 | 账号/手机号 + 密码；用户名需字母开头 3-32 位 |
| 拼图滑块验证码 | 表单下方滑块 | 服务端出题、缺口坐标存 Redis；一次性消费、指纹绑定 IP+UA、最小驻留 0.2s、误差 >8px 拒绝、60s 过期 |
| 手机号 | 登录页「手机号」切换 | **演示交互**（面板注释「无后端接口」）；后端提供 `wx-phone-login` 接口供微信小程序端调用 |
| 微信小程序码 | 登录页「扫码」切换 | **演示二维码交互**（面板注释「无后端会话」）；后端提供 `wx-login` / `wx-qrcode/generate` 接口，小程序内确认登录可自动建号 |
| OAuth | 表单下方图标 | GitHub / Gitee / 微信开放平台 / QQ，四渠道图标对应登录 |

- 「注册」：用户名唯一（重复报「已存在相同用户名称的账号」），注册即 `status=0` 的正式账号，成功后自动回填并登录。
- 「忘记密码」：仅**记录请求**，不接受直接改密；无论账号是否存在、停用、超管，返回信息完全一致（防用户枚举），只对启用中的非超管用户写日志。
- 演示账号一键填充：登录区提供演示账号快捷填入（默认 `super`，来自后端初始化数据）。

### 验证码细节

只提供拼图滑块一种（无图形验证码/短信）。机制：

- `GET /system/auth/captcha/get` 出题返回图片与 `captcha_key`；
- `POST /system/auth/captcha/slider/complete` 校验滑块位置与滑动轨迹；
- 状态机 `pending → verified` 一次性消费；服务端返回的业务 token（`captcha_token`）用于登录表单扩展字段。

滑块是纯前端交互，无强人机证据，属威慑性校验（源码 docstring 已说明）。

### OAuth 回跳

- `GET /system/auth/oauth/{provider}/login|callback`，provider = `wechat（微信开放平台扫码）| qq | github | gitee`。
- state 存 Redis（键 `oauth_state:`，TTL 600s）防 CSRF；成功回跳 `{frontend}?access_token=...&refresh_token=...`，失败 `?oauth_error=...`。
- 回跳域名走白名单（防 Host 头注入）；渠道密钥未配置时返回 500 而不是误报参数错误。
- 登录后可进入 **个人中心** 查看第三方账号绑定状态（github/gitee/wx/qq）。

## 会话与 Token 机制

- 双 JWT（HS256）：access 与 refresh 各自 **12 小时** 过期；JWT 只装 `session_id`，完整会话信息存 Redis（`user_session:{session_id}` + `access_token:{session_id}` / `refresh_token:{session_id}` 三键）。
- **滑动续期**：access 过期后以 refresh 换新；每次刷新**轮换** access 和 refresh，若 Redis 中 refresh 与提交值不一致，判定疑似重放 → 撤销整个会话。
- 会话绝对上限 7 天（`SESSION_MAX_LIFETIME_SECONDS=604800`），到期需重新登录。
- 退出：删除三键，登出接口幂等。
- 登录限流：`LOGIN_RATE_LIMIT_MAX_ATTEMPTS=10` 次 / `LOGIN_RATE_LIMIT_WINDOW_SECONDS=60` 秒（Redis 固定窗口，Redis 异常时放行）。
- 登录成功/失败均写登录日志，记录用户名、状态（1=成功 2=失败）、IP、登录位置（ip2region 本地离线库，受 `ip_location_enable` 参数控制）、操作系统与浏览器。
- 微信小程序登录链路（后端能力，供小程序端接入）：`POST /system/auth/wx-login`（uni.login code 换 openid，可自动注册）、`POST /system/auth/wx-phone-login`（getPhoneNumber code 换手机号）、`POST /system/auth/wx-qrcode/generate`（小程序码图片，scene ≤32 / page ≤128 / width 280-1280）。

## 顶栏与布局

登录后进入三区域布局：左侧 `#app-sidebar`（菜单）、顶部 `#app-header`（顶栏）、中间 `#app-content`（页面内容区）+ 全局水印与 AI 助手入口。

顶栏（从左到右，均可在基础设置中关闭）：Logo、菜单折叠按钮、刷新、快速入口 FaFastEnter、面包屑（左/混合菜单模式）、横向菜单、全局搜索（`Ctrl/⌘+K`）、全屏、组件尺寸、语言切换（中/英）、通知中心（未读角标 max 99+）、设置抽屉入口、用户菜单（头像/昵称 → 个人中心、锁屏、注销）。

### 设置抽屉能力

| 分组 | 选项 |
| --- | --- |
| 主题风格 | 亮色 / 暗色 / 跟随系统 |
| 菜单布局 | Left（左侧）/ Top（顶部）/ Mixed（混合）/ Dual Column（双列） |
| 菜单风格 | design / dark / light |
| 系统主题色 | 7 种预设主色 |
| 盒子样式 | border（边框）/ shadow（阴影） |
| 容器宽度 | full（全宽）/ boxed（定宽居中） |
| 基础设置 | 多页签、手风琴、折叠侧栏、快速入口、刷新按钮、面包屑、工作页签、语言切换、菜单搜索、全屏、尺寸选择、通知、NProgress、色弱、水印、Logo、新手指引、AI 助手入口、菜单展开宽度、页签风格、页面过渡动画、圆角 |

布局与主题偏好持久化到本地存储（`setting.store.ts`）。

### 工作标签页（页签）

- 三种风格：`tab-default`（默认）/ `tab-card` / `tab-google`（Chrome 风格，默认）。
- 操作：左右滚动、书签星标、中键关闭、右键菜单、固定标签（fixedTab，不可关闭）。
- 页面内容区按菜单 `keepAlive` 常驻（KeepAlive 缓存），含返回顶部与节日滚动文案。

### 其他全局能力

- **全局搜索**（`Ctrl/⌘+K`）：菜单搜索 + 历史记录（可删除），↑↓ 选择、回车跳转、ESC 关闭。
- **快速入口**：Popover 应用列表（用户管理、角色管理、定价、聊天、官方文档、技术支持、更新日志、操作手册）与快捷链接（登录/注册/忘记密码/操作日志/个人中心）；节日自动礼花，`Ctrl/⌘+Shift+P` 手动触发烟花。
- **锁屏**：首次设置锁屏密码 → 全屏锁页（时钟 + 解锁表单）；检测到开发者工具打开时全屏警告「为了系统安全，请关闭开发者工具」。
- **新手指引**：首次登录引导（完成/跳过即不再显示）。
- **水印**：全局水印显示当前登录用户名。
- **AI 助手**：右下角魔方入口（`FaAiAssistant`），由基础设置 `userEnableAi` 开关控制。

## 个人中心

入口：顶栏用户菜单 → 个人中心（`/fastlink/profile`，壳层路由，不在侧栏显示）。

功能：头像上传（裁剪）、基本信息维护、**密码修改**、第三方账号绑定状态展示（github/gitee/wx/qq）。

## 打开方式与端口

- 开发模式：`front-web` 目录 `pnpm dev`，默认 `http://127.0.0.1:5180`（`VITE_PORT=5180`），`/api/v1` 由 Vite 代理转发。
- 访问模式 `VITE_ACCESS_MODE=mixed`：菜单由后端动态注册，参考静态壳层路由（首页/登录/404 等）。
- 刷新页面（F5）时 iframe 类路由（如 Swagger 文档）从 sessionStorage 恢复链接。
