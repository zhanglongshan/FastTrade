# FastTrade 管理后台操作文档

本目录集中说明管理后台（平台底座）的登录、系统管理、日志监控、定时任务与存储、运维开发工具与 AI 助手。所有页面与操作步骤都在这里维护，与 [量化模块文档](../quant/README.md) 平级、互不重叠。

> 管理后台底座源自 [FastapiAdmin](https://gitee.com/fastapiadmin/FastapiAdmin)，按“用户 → 角色 → 菜单 → 按钮权限码”的模型二次开发；量化页面（`/quant/*`、`/quant-astock/*`、`/quant-futures/*`）也作为普通菜单挂载在同一后台中，登录与权限体系完全共用。

## 1. 功能总览

侧栏菜单（由后端 `sys_menu` 种子数据注册，登录后按权限动态生成）：

| 一级目录 | 页面 | 说明 |
| --- | --- | --- |
| **首页** | 工作台 | 仪表盘统计卡片与快捷入口 |
| **系统管理** | 菜单、字典、参数、部门、岗位、角色、用户、日志、公告、工单、版本 | 组织架构、账号权限、配置参数、审计日志、公告工单 |
| **监控管理** | 在线用户、服务器监控、缓存监控 | 在线会话强退、CPU/内存/磁盘、Redis 监控与键浏览 |
| **接口管理** | Swagger 文档 | iframe 内嵌 FastAPI `/docs` |
| **代码管理** | 代码生成 | 表结构 → 标准 CRUD 前后端代码 |
| **AI管理** | AI 智能助手、会话记忆 | 多模型对话、模型配置、会话记录、只读工具 |
| **任务管理** | 定时任务（调度器监控/节点管理）、存储管理（流程/节点/文件浏览/传输任务） | APScheduler 调度、多渠道文件传输编排 |
| **运维管理** | SQL 控制台、SSH 运维 | 外部 MySQL/PostgreSQL 只读查询、SSH 终端与批量执行 |
| **量化** | 各市场下载/图表/回测/模拟盘/实盘 | 见 [量化模块文档](../quant/README.md) |

首页地址 `/home`；未配置菜单的普通用户登录后默认跳转 `/home`。菜单不存在或没有权限时进入 404/403 页。

## 2. 账号与登录

- 初始化数据提供三个演示账号：`super`（超级管理员）、`admin`（管理员，超管）、`user`（普通用户）；演示密码与部署说明见根 [README](../../README.md)（测试环境固定使用 `admin / admin123`，仅测试生命周期内有效）。
- 登录方式：账号密码、拼图滑块验证码、手机号、微信小程序码扫码、OAuth（GitHub / Gitee / 微信开放平台 / QQ）。
- 会话安全：双 JWT（access/refresh）各 12 小时过期、滑动续期、会话绝对上限 7 天；刷新令牌轮换 + 重放检测；登录限流默认 10 次 / 60 秒。
- 登录失败同样写入登录日志，可进入 **系统管理 → 日志 → 登录日志** 审计。

详见 [01-登录与个性化](./01-登录与个性化.md)。

## 3. 权限模型

- 权限码挂在菜单（尤其 `type=3` 按钮）的 `permission` 字段上，经 **用户 → 角色（sys_user_roles）→ 菜单（sys_role_menus）** 两级关联在登录时聚合到会话。
- 前端按钮用 `checkPerm` / `perm-*` / `v-hasPerm` 按权限码显隐，后端接口用 `Security(AuthPermission([...]))` 校验，**两侧使用完全相同的权限码字符串**。
- 超级管理员（`is_superuser=true`）跳过权限校验、天然全量；角色 `id=1` 为系统默认角色，分配权限/编辑/删除被前端保护。
- 各模块完整权限码表见 [07-权限与安全](./07-权限与安全.md)。

## 6. 边界说明

- **状态语义统一 0=启用 1=停用**（用户/角色/菜单/部门/岗位/字典/公告/参数/存储源/主机等）；仅登录日志为 `1=成功 2=失败`，工单（0-3）、版本（0=草稿 1=已发布 2=已回滚）为业务枚举。
- 删除为**物理删除**（接口传 `ids` 批量删），无回收站；权限变更即时生效（前端 `refreshPermissions()` 同步本地）。
- 高危能力默认收紧：代码块型定时任务执行默认关闭（`SCHEDULER_ALLOW_CODE_EXEC=false`）、SQL 控制台只读校验 + 写确认、SSH 终端与代码生成均有白名单/路径约束，详见对应分册与 [07-权限与安全](./07-权限与安全.md)。
- 敏感配置与凭据（`.env.dev`/`.env.prod`、SSH 密码/私钥、dbconsole 连接密码、存储节点凭据）一律加密落库、接口不回传明文，**不要提交到仓库**。
