# 06 AI助手

AI管理包含两个页面：**AI智能助手**（对话）与**会话记忆**（会话记录管理）。

## AI 智能助手（/ai/chat）

左侧会话栏（会话列表、新建、模型配置入口）+ 中间聊天区（消息流、连接状态、清空、输入框）+ 右侧模型配置抽屉。

- 窄屏（≤800px）自动收起会话侧栏。
- 对话通道：
  - **WebSocket 流式**：`WS /api/v1/ai/chat/ws`，**token 经 Sec-WebSocket-Protocol 传递**（`["access_token", "access_token.{token}"]`）而非 URL 查询参数——避免打进访问日志；流式逐块返回，结束标记 `[DONE]`，用户打断发送 `action=stop`，服务端回 `[STOPPED]`；连接握手期（CONNECTING/OPEN/CLOSING）拒绝重入，防止泄漏旧连接。
  - **HTTP 非流式**：`POST /ai/chat/ai-chat` 一次请求返回完整回复。
- 前端需配置 `VITE_APP_WS_ENDPOINT`（开发默认 `ws://localhost:8001`，见 `front-web/.env.development.example`）。

### 模型配置

环境变量默认（`backend/env/.env.example`）：`OPENAI_API_KEY`、`OPENAI_MODEL`、`OPENAI_BASE_URL`（注释标注为 OpenAI 兼容 Base URL，如 `https://api.minimax.chat/v1`，非 OpenAI 官方专属）。

- 用户级模型配置存 **Redis**（`ai_model_config:items:{user_id}` 列表 + `active:{user_id}` 激活 ID + 每用户互斥锁，TTL 控制）。
- 接口：`GET/POST/PUT/DELETE /ai/chat/model`、`POST /model/{id}/activate`（`__default__` 表示回归系统默认）。
- **探测类不落库**：`POST /model/available` 拉取模型列表；`POST /model/test` 连通性测试（向 `{base_url}/chat/completions` 发 `{"model", "messages":[...], "max_tokens":1}`，返回 `{ok, model_id, latency_ms}`）。
- 拼接规则：优先用户激活配置（base_url/api_key/model_id/temperature 覆盖），否则 `settings` 兜底；运行时封装为 Agno `OpenAILike(id, api_key, base_url, temperature, timeout=60.0)`，temperature 默认 0.7（范围 0.0-2.0）。
- 模型密钥（API Key）按用户隔离存 Redis，接口不回传明文；部署时应关注 Redis 访问控制。

### 对话行为

- Agno Team/Agent：`add_history_to_context=True`、`read_chat_history=True`、**历史上下文取最近 3 轮**、`add_datetime_to_context=True`、`markdown=True`；`is_generating` 互斥 + stop_event 支持打断。
- 持久化：会话/消息存库，前端「会话记忆」页可管理。

### 只读工具（默认关闭）

「AI 模型配置」抽屉内有独立开关，共 5 个**只读工具**：

| 工具 | 说明 |
| --- | --- |
| `server_status` | CPU / 内存 / 磁盘 |
| `storage_sources` | 存储源名称/协议/状态（**不含凭据**） |
| `storage_files(source_name, path, bucket)` | 列文件 |
| `cron_jobs(limit)` | 定时任务（触发方式/下次执行/状态，≤50 条） |
| `redis_keys(pattern, limit)` | 只列键名（≤200 条） |

安全设计：

- 明确不移植 FastHub 的 `run_host_command`（= RCE 类工具）；
- 工具由 auth/redis 闭包注入，`_assert_no_injected_params` 禁止签名出现 auth/self/cls/redis/db；
- 异常转 `{"error":...}` 不中断对话；
- `GET /ai/chat/tools` 输出工具清单（给模型与用户看）。

## 会话记忆（/ai/memory）

AI 会话记录管理页：会话列表查询（标题搜索、include-audit 审计筛选）、**重命名**、**删除/批量删除**、详情查看（metadata JSON + user/assistant 消息时间线）。

- 所有会话按创建者隔离；普通用户只能看到并管理自己的会话。
- 权限码：`module_ai:chat:query` / `:detail` / `:create` / `:update` / `:delete`；WebSocket 连接使用 `module_ai:chat:query`（超管或 `*:*:*` 直接放行）。

## 前端入口开关

系统设置 → 基础设置 →「AI 助手入口」`userEnableAi` 决定右下角 `FaAiAssistant` 魔方入口显隐（`fa-ai-assistant/index.vue`，默认关闭 `aiEnabled=false`）；打开后登录即可在任意页面唤起 AI 助手。
